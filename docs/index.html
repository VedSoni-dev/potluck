What works

Ask for a tool

"@potluck build us a dinner poll" turns one sentence into a ready tool with your group's names filled in.

Seating chart

Drag friends between rooms or tables. Full tables refuse the drop.

Polls

One tap to vote, live bars, the leader marked.

Expense split

Log who paid; it works out who owes whom, to the cent.

Brackets, itineraries, checklists

Single elimination with byes, timed day plans, who-brings-what.

Share by link

The whole space packs into the link itself. Nothing is stored on a server.

Not yet

  • No live multiplayer: a share link is a snapshot until someone shares a fresh one back.
  • No file uploads on the board (links and notes only).
  • Six tool types; the agent can't invent new kinds of tools yet.

Run it yourself

git clone https://github.com/VedSoni-dev/potluck
cd potluck && npm install && npm run dev
